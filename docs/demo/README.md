# Demo recording kit (B22)

Target: **4 minutes 30 seconds**. This is a recording script, not a claim that a video has been recorded.
Use the signed, tested build. Keep airplane mode visible at the start and end. A real model file and a real phone are required
for the model sections; if unavailable, show the template notice and say so. Never edit template text to resemble model output.

| Time | Screen and action | Narration |
| --- | --- | --- |
| 00:00–00:20 | Show airplane mode, launch Sahay | Sahay builds a personal study roadmap on this phone. The APK has no internet permission. |
| 00:20–00:55 | Intake: goal, experience, hours, deadline, interests, language | A learner chooses a goal and time budget. Free text falls back to domain chips when unclear. |
| 00:55–01:30 | Diagnostic: confidence slider, hint ladder, wrong answer | Answers, confidence, response time and hints become the learning record. Show a pre-recorded diagnostic summary after the live example; label the time cut. |
| 01:30–02:00 | Roadmap: why-this, prerequisites, changed-plan sentence | The deterministic engine decides order and timing. Every change has a reason. |
| 02:00–02:40 | Study and tutor: source note, analogy, question, streaming and Stop | Explanations use the skill note. Show the real model if available, otherwise clearly show the template notice. |
| 02:40–03:15 | Dashboard and recovery | Show mastery, confidence calibration, active misconceptions and what recovery dropped. Do not claim unmeasured learning gains. |
| 03:15–03:50 | Scan preview/edit and QR pages | Scan text stays on the device. Review the draft. QR pages carry the complete learner snapshot and must all be scanned. |
| 03:50–04:15 | Device and settings: measured values, export, delete | Show actual measurements; absent values stay unmeasured. Demonstrate local data control. |
| 04:15–04:30 | Airplane mode, status and limitations | Phone performance, language quality and prototypes are stated according to recorded evidence. |

Hindi reviewer check them before uploading. Upload the completed video and add the real link to README only after recording.
