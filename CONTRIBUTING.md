# Contributing

- Trunk-based: short branches named `<issue-id>-short-name` (for example `A04-jni-wrapper`), merged into `main` by pull request.
- Every pull request links its issue (`Closes #N`) and is reviewed by one of the other two team members.
- CI must be green: unit tests, `scripts/ci_checks.py` (manifest and content validation), debug APK build.
- Update the status line in README.md and SPRINT.md when a feature changes state: Not started, In progress, Done, Cut.
- Daily 15-minute standup; ask mentors via tech-queries@armbharatchallenge.com with "PS4" in the subject.
- Feature freeze: 21 Nov. After that only bug fixes, benchmarks, video and report.
